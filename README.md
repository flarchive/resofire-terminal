# Terminal — Flarum 2.x Theme

A monospace dark theme for Flarum 2.x. Acid green accents on near-black backgrounds. DM Mono throughout.

## Installation

```bash
composer require resofire/terminal
```

Then enable the extension in your Flarum admin panel.

## Requirements

- Flarum 2.x
- flarum/tags (recommended — enables coloured tag tiles in the sidebar)
- flarum/flags (optional — flags dropdown moves to the sidebar user block)
